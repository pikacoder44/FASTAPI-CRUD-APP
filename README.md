# Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/pikacoder44/FASTAPI-CRUD-APP.git
   ```
2. Install the required dependencies:
   ```bash
    pip install -r requirements.txt
    ```
3. Run the FastAPI application:
   ```bash
   uvicorn main:app --reload
   ```
